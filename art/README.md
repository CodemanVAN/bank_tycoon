# Starway Bank — Modern Tech Blue Art Pack

本包是首轮美术方向参考工程包，供 UI、美术、前端与外包协作使用。

## 目录
- `01_visual/` 主视觉参考图、原始界面参考
- `02_tokens/` 色彩 JSON、CSS 设计令牌、色卡 PNG
- `03_guidelines/` 美术基底、资产规格、PDF 报告
- `04_prompts/` 统一美术生成提示词

## 使用建议
1. 先确认主视觉与色彩体系，再拆分场景、角色和 UI 资产。
2. 将 `design_tokens.css` 接入前端主题变量。
3. 以 1920×1080 作为首轮 UI 设计基准，后续做 16:9 与窗口缩放适配。
4. 生成式图像仅作风格/构图参考；正式生产资产需重新绘制、拆层、校对文字和图标。
5. 本包不包含可直接运行的游戏工程、可编辑 PSD/AI 源文件或完整逐帧动画；这些需按资产规格进一步制作。
