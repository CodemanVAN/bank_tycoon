# 统一美术生成提示词

## 主场景
2.5D isometric pixel-art bank management simulation, premium modern fintech atmosphere, Starway Bank, warm detailed bank interior, navy and electric-blue HUD, cyan focus accents, readable clean Chinese interface, balanced composition, consistent orthographic isometric perspective, crisp pixel edges, polished game UI.

## 资产一致性约束
- 固定光源：室内暖色顶光 + 冷色屏幕补光。
- 固定视角：等距 2.5D，所有建筑和家具保持相同透视。
- 固定角色比例：Q 版员工，头身比约 1:2.2 至 1:2.8。
- UI 使用统一圆角、描边、投影和色彩语义。
- 不要随意更改品牌名、核心数据字段、面板层级和图标语义。
- 避免过量霓虹、过度玻璃拟态、低对比小字、混用透视角度。
