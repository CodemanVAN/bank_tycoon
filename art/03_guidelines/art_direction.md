# 星海银行｜现代科技蓝美术基底

## 1. 项目定位
- 类型：银行经营模拟 / 管理策略 / 轻度城市建造。
- 核心气质：可信赖的金融机构 + 轻科幻金融科技 + 亲和的像素经营世界。
- 视觉关键词：专业、清晰、明亮、秩序、精致、可读。
- 画面语言：2.5D 等距视角场景 + 像素角色与设施 + 现代 HUD 面板。

## 2. 艺术基底
- 主色调：深空海军蓝与科技蓝，建立稳定、专业的金融科技氛围。
- 高亮色：青色只用于焦点、选中态、描边和少量能量光效；避免整块大面积荧光。
- 金融语义：金色专用于现金、收益、奖励与高价值资产。
- 状态语义：绿色=正向/通过；红色=风险/亏损；紫色=特殊事件/研究。
- 场景底色：室内暖木色、米白地砖、绿植作为冷色 UI 的视觉平衡，保留原图温暖的经营氛围。

## 3. 色彩比例建议
- 60% 深蓝/蓝灰：背景、面板、导航、信息容器。
- 25% 场景中性色：木色、石材、米白、建筑材质。
- 10% 科技蓝/青色：交互焦点、选中、边框和图表主线。
- 5% 语义强调色：金、绿、红、紫。
比例是全屏视觉面积的设计目标，不是硬性像素配额。

## 4. 布局与信息层级
1. 顶栏：品牌、现金、每日收益、满意度、员工数、日期时间、暂停/倍速。
2. 左侧导航：总览、建筑、部门、员工、政策、事件、市场、科技；当前页面采用高亮蓝底和清晰图标。
3. 中央主场景：银行大厅与部门空间是视觉主体，UI 遮挡控制在必要范围。
4. 左下经营概览：收入、利润、满意度、风险；数字右对齐，变化值用语义色。
5. 右侧随机事件：事件插画、简短说明、选项按钮；风险/收益写清楚。
6. 底部管理区：政策树、新政策、员工管理、市场趋势；卡片边界统一，内部内容留白充足。

## 5. 面板与交互规范
- 面板：深蓝半透明底，建议 88–94% 不透明度；1px 蓝灰描边。
- 主按钮：科技蓝填充，白色文字；悬停/焦点增加青色外发光。
- 次按钮：蓝灰填充或透明底描边。
- 危险按钮：红色只用于确认风险操作，不用作普通装饰。
- 圆角：小控件 6px；普通卡片 10px；大型面板 14px。
- 阴影：低饱和深蓝投影；避免黑色硬阴影。
- 文字：中文 UI 使用清晰无衬线字体；数字使用等宽/数字友好字体，表格对齐。

## 6. 可读性与无障碍
- 正文建议不低于 14px（以 1080p 基准）；次级说明不低于 12px。
- 文字与面板对比度目标至少 4.5:1；关键数值避免只用颜色表达，增加 + / -、箭头或文字标签。
- 青色光晕不可覆盖小字号文字；图表线条同时使用颜色与图例/点型区分。
- 不要把所有边框都做成强霓虹；仅焦点面板、当前选中项和关键操作使用发光。

## 7. 场景资产基底
- 建筑：银行外立面、玻璃幕墙、入口门廊、室内隔断、服务柜台。
- 家具：办公桌、电脑、座椅、会议桌、沙发、盆栽、饮水机。
- 场景装饰：喷泉、落地窗、绿植、城市天际线、道路与人行道。
- 角色：客户、柜员、经理、分析师、安保、访客；统一头身比与轮廓线。
- UI 图标：建筑、员工、政策、事件、市场、科技；采用统一线宽和圆角像素风。

## 8. 动效方向
- 选中态：150–220ms 蓝色亮度提升 + 轻微描边发光。
- 数值变化：短促上浮/淡入，正向绿色、负向红色。
- 事件弹窗：轻微缩放进入，避免大幅弹跳。
- 场景循环：角色待机、屏幕闪烁、喷泉水面、树叶轻摆；低频、低幅度，避免干扰经营信息。
