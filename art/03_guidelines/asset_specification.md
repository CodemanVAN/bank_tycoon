# 美术资产规格建议（首期）

| 资产组 | 建议内容 | 建议源文件 | 备注 |
|---|---|---|---|
| 场景底图 | 银行大厅等距场景、部门房间、城市背景 | PNG / PSD | 分层绘制；场景与 UI 分离 |
| 建筑模块 | 外墙、玻璃门、柱体、柜台、隔断 | PNG spritesheet | 模块化拼装，统一等距角度 |
| 家具道具 | 桌椅、电脑、沙发、盆栽、喷泉 | PNG spritesheet | 透明背景，统一光源方向 |
| 角色 | 客户、柜员、经理、分析师、安保 | PNG spritesheet | 统一比例；待机/行走/工作动作 |
| UI 面板 | 顶栏、侧栏、卡片、事件弹窗 | SVG / PNG | 优先矢量，适配分辨率 |
| 图标 | 建筑、部门、员工、政策、市场、科技 | SVG | 统一 24/32px 网格 |
| 图表 | 收益曲线、风险指标、趋势图 | SVG / Canvas | 数据与皮肤分离 |
| 字体 | 中文 UI 字体、数字字体 | TTF/OTF 授权文件 | 运行时确认授权与回退字体 |

## 尺寸与导出建议
- 设计基准：1920×1080；适配 16:9，关键 UI 安全边距 24px。
- 像素场景：按 2× 或 3× 整数倍导出，避免非整数缩放造成模糊。
- UI 矢量：SVG 优先；光效、复杂纹理可导出 PNG。
- 透明资产：PNG-32；背景图：PNG 或 WebP（按画质/体积权衡）。
- 命名：`类别_主题_状态_尺寸_版本`，例如 `ui_button_primary_default_256_v01.png`。
- 九宫格：面板与按钮如需缩放，采用 9-slice，避免边角拉伸。
