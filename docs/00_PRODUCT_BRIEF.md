# 00 — 产品简介（Product Brief）

## 一句话定义

一款 2D 像素风银行经营模拟游戏：玩家在每天的实时营业压力下调度客户与员工，通过招聘、部门建设、银行策略和风险管理，把一家小型银行逐渐发展成有独特经营风格的金融机构。

## 产品幻想

“我从亲自面试第一个柜员、处理第一位储户开始，逐渐建立一套能自行运转的银行组织；我设计它的文化、部门和经营哲学，并在经济变化中承担过去决策的后果。”

## 核心差异化

1. **日内实时、日终结算：** 真实可见的大厅运营和即时人员调度，叠加跨日的经济结果。
2. **从亲力亲为到组织自动化：** 部门不是纯数值 Buff，而是解锁新工作流程和管理权限。
3. **银行策略构筑：** 长期政策树让玩家形成稳健、扩张、科技、企业金融或私人银行等不同路线。
4. **延迟因果事件：** 经济周期、贷款风险、员工流失和监管事件会回头检验玩家的经营选择。
5. **可扩展内容：** 数据型 Mod 和多语言为长期内容生态预留接口。

## 目标玩家

- 喜欢经营模拟、组织管理、策略构筑和资源调度的玩家。
- 喜欢“看着系统运作并不断优化”的玩家。
- 不要求懂真实银行业务；游戏通过清楚的指标和反馈解释复杂机制。

## 目标平台与控制

- 首要平台：Windows 桌面；后续评估 Linux/macOS。
- 首要输入：鼠标和键盘。
- 主要画幅：16:9；支持窗口化和多分辨率。
- 不以触屏或手柄作为首发目标，但 UI 不应完全依赖悬停。

## 产品边界

- 不是完整真实银行监管/会计软件。
- 不是军事 RTS，不包含战斗。
- 不做多人在线经济、网络交易或真实货币支付。
- 初版不开放任意脚本 Mod，不承诺任意 Mod 组合都兼容。
- 首发先做单一分行，不做多城市金融集团全套经营。

## 成功体验指标（待试玩验证）

- 玩家能在 30 秒内理解当天最紧急的运营问题。
- 玩家能解释一次调度行为如何改变排队、满意度或利润。
- 成立一个部门后，至少有一项操作流程发生质变。
- 稳健与激进路线在同一事件下产生不同的合理选择。
- 玩家能说出一件由自己过去决策引发的危机或成功故事。
